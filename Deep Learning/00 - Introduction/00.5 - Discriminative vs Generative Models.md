## The Core Distinction

| | **Discriminative** | **Generative** |
|---|---|---|
| **What is learned** | $p(y \mid \mathbf{x})$ — conditional probability of label given input | $p(\mathbf{x})$ or $p(\mathbf{x}, y)$ — the data distribution itself |
| **Goal** | Learn a decision boundary to map inputs to outputs | Learn how data is generated; synthesize new samples |
| **Training signal** | Labeled pairs $(\mathbf{x}, y)$ | Usually unlabeled data $\mathbf{x}$ |
| **Output** | Class labels or regression values | New data points similar to training data |

## Discriminative Models

Discriminative models focus on learning the **mapping from input to output**. They model the conditional distribution $p(y \mid \mathbf{x})$ directly, without caring about how the input $\mathbf{x}$ was generated.

Examples: perceptrons, feedforward neural networks for classification, SVMs, CNNs for image recognition.

These are the models used in **supervised learning**: classification and regression.

## Generative Models

Generative models aim to learn the **underlying distribution** $p(\mathbf{x})$ of the data. Once the distribution is learned, the model can **sample** new examples that resemble the training data.

The vast majority of unsupervised deep learning revolves around generative models.

### Key Concepts

**Synthesis = Sampling**: generating new data points by sampling from the learned distribution. Used in image generation, text generation, data augmentation.

**Latent Space**: generative models often map data into a compact lower-dimensional representation (latent space $\mathbf{z}$). New samples are generated by sampling from this latent space and decoding back to the original space.

$$\mathbf{z} \sim p(\mathbf{z}) \xrightarrow{\text{decode}} \mathbf{x} \sim \hat{p}(\mathbf{x})$$

**Structured Output Learning**: generative models are closely related to structured output prediction — the output is not a single label but a structured data point (image, sequence, etc.).

### Main Architectures

| Model | Mechanism |
|---|---|
| **GANs** (Generative Adversarial Networks) | Two networks (Generator + Discriminator) compete: generator creates fake samples, discriminator distinguishes real from fake |
| **VAEs** (Variational Autoencoders) | Learn a latent representation of the data; generate samples by decoding from the latent space |
| **Diffusion Models** | Model the data generation process by gradually refining random noise into realistic samples |

These are organized in a hierarchy:

$$\text{Unsupervised Learning} \supset \text{Generative Models} \supset \text{Probabilistic Generative Models (PGMs)}$$

### Applications

- **Data Availability**: augment limited datasets with synthetic examples (medical imaging: MRIs, CT scans)
- **Content Creation**: video game design, art generation, simulation
- **Anomaly Detection**: flag inputs that have low probability under the learned distribution
- **Scientific Research**: simulate complex physical phenomena or systems

## When to Use Which

- Use **discriminative** models when you have labeled data and need to predict outputs (classification, detection, segmentation)
- Use **generative** models when you want to understand the data distribution, generate new samples, or work without labels
