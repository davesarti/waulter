## Motivation: The XOR Problem

A single perceptron is a **linear classifier** — it can only separate classes with a straight line (or hyperplane). This means it fundamentally fails on **non-linearly separable** problems.

No single hyperplane can separate the XOR outputs — this exposed a fundamental flaw in the perceptron model and triggered the **first AI winter** (1969, Minsky & Papert).

## Solution: Stack Multiple Perceptrons

By stacking perceptrons into multiple layers, we can create a network capable of learning **compositions of non-linear functions**, solving problems like XOR.

## Architecture

An MLP consists of three types of layers:

- **Input Layer**: receives the raw input data $\mathbf{x}$
- **Hidden Layers**: intermediate layers where neurons learn increasingly abstract representations of the data
- **Output Layer**: produces the final prediction $\hat{\mathbf{y}}$

All neurons between adjacent layers are **densely connected** (each neuron connects to every neuron in the next layer).

## Forward Pass: Single Hidden Layer

For a network with one hidden layer (layers labeled (1) and (2)):

**Hidden layer** — pre-activation for neuron $j$:
$$z_j = \sum_i \theta_{i,j}^{(1)} x_i + \theta_{0,j}^{(1)}$$

**Output layer** — prediction for output $k$:
$$\hat{y}_k = h\!\left(\sum_i \theta_{i,k}^{(2)}\, h(z_i) + \theta_{0,k}^{(2)}\right)$$

Each layer applies a different set of weights, allowing the network to learn different aspects of the input.

## Capacity

MLPs can be used for **both classification and regression** tasks. Thanks to the combination of multiple non-linear transformations across layers, an MLP can theoretically approximate any continuous function (**Universal Approximation Theorem**, Cybenko 1989).

In practice, **deeper networks** (more hidden layers) tend to outperform shallow ones because they can:
- Learn **hierarchical representations** (e.g., edges → shapes → objects)
- Represent complex functions **more efficiently** with fewer neurons per layer

## Training Challenge

The perceptron training rule cannot be directly applied to hidden layers, since we don't have ground-truth labels for hidden neurons. This problem was solved in **1986** by Rumelhart, Hinton, and Williams with the backpropagation algorithm, which computes gradients layer by layer using the chain rule.
