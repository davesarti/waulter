## Biological Inspiration

AI was originally inspired by the goal of **emulating human intelligence**. The design of artificial neural networks was directly inspired by the **biological neuron**.

A biological neuron consists of:
- **Dendrites**: branch-like structures that receive signals from other neurons
- **Cell body (Soma)**: contains the nucleus, processes incoming signals
- **Axon**: long projection that transmits signals away from the cell body
- **Synapses**: tiny junctions at the end of the axon where signals are transmitted chemically or electrically

Key properties:
- Information flows: dendrites → cell body → axon
- Synapses vary in strength, influencing how strongly signals are passed on
- Synapses can be **excitatory** (encourage transmission) or **inhibitory** (reduce transmission)

## McCulloch–Pitts Neuron (1943)

In **1943**, Warren McCulloch and Walter Pitts proposed the first computational model of a neuron (*"A Logical Calculus of the Ideas Immanent in Nervous Activity"*). This was the first **"electronic brain"**.

The model:
$$\hat{y} = h\!\left(\sum_i x_i\right), \quad h(x) = \begin{cases} 1 & x \geq 0 \\ 0 & x < 0 \end{cases}$$

Characteristics:
- **Binary inputs**: each input $x_i \in \{0, 1\}$
- **No weights**: all inputs treated as equally important
- **Threshold function**: if the sum of active inputs exceeds a threshold → output 1, else 0

With this model, McCulloch & Pitts showed it was possible to implement basic Boolean logic (AND, OR, NOT).

## Perceptron (Rosenblatt, 1958)

Frank Rosenblatt introduced the **Perceptron**, adding two key innovations over the McCulloch–Pitts model:

- **Learnable weights** $\theta_i$: inputs are no longer equally important; weights are learned from data
- **Bias term** $\theta_0$: allows the decision boundary (hyperplane) to be shifted, so it does not have to pass through the origin

$$\hat{y} = h(\boldsymbol{\theta}^T \mathbf{x} + \theta_0)$$

The perceptron is a **linear classifier**: it learns a hyperplane that separates data into two classes. It works well only for **linearly separable** data.

### Perceptron Training Rule

Given training set $\mathcal{T} = \{(\mathbf{x}_1, y_1), \ldots, (\mathbf{x}_N, y_N)\}$, $y_i \in \{0,1\}$, and learning rate $0 < \eta < 1$:

1. Initialize weights $\theta_i$ and bias $\theta_0$ to small random values
2. Iterate until all training examples are classified correctly:
   - Select random sample $(\mathbf{x}_i, y_i)$
   - Compute $\hat{y}_i = h(\boldsymbol{\theta}^T \mathbf{x}_i + \theta_0)$
   - Update: $\boldsymbol{\theta}^{t+1} = \boldsymbol{\theta}^t + \eta(\hat{y}_i - y_i)\mathbf{x}_i$, $\quad \theta_0^{t+1} = \theta_0^t + \eta(\hat{y}_i - y_i)$

If the prediction is correct → no update. If incorrect → weights and bias are adjusted to move the decision boundary toward the correct position.

## Modern Artificial Neuron

Over time, the hard threshold function was replaced by more flexible **activation functions** — arbitrary non-linear functions that produce richer, more expressive models.

The computation inside a modern artificial neuron:

$$z = \sum_i \theta_i x_i + \theta_0 \qquad \hat{y} = h(z)$$

Steps:
1. Each input $x_i$ is multiplied by its corresponding weight $\theta_i$
2. The weighted inputs are summed and a bias $\theta_0$ is added → pre-activation $z$
3. $z$ is passed through a non-linear activation function $h$ to produce the output

This non-linearity is **crucial**: it allows the network to learn complex patterns and model non-linear decision boundaries.
