## Tom Mitchell's Definition

> *"A computer program is said to learn from **experience E**, with respect to some class of **tasks T**, and **performance measure P**, if its performance at tasks in T, as measured by P, improves with experience E."* — Tom Mitchell

Three key components of any ML problem:
- **T (Task)**: what the system is trying to do
- **P (Performance Measure)**: how success is evaluated
- **E (Experience)**: the data used for learning

## 1. Supervised Learning

The model is trained on **labeled data**: input-output pairs $(\mathbf{x}_i, y_i)$.

$$\mathcal{T} = \{(\mathbf{x}_1, y_1), \ldots, (\mathbf{x}_m, y_m)\}$$

The goal is to learn a function $f: \mathbb{R}^d \to \mathcal{Y}$ that maps inputs to outputs.

### Classification

Output space is **categorical** (discrete labels):

$$f: \mathbb{R}^d \to \{1, 2, \ldots, k\}$$

- **Binary classification**: two classes (e.g., spam vs. not spam)
- **Multiclass classification**: $k$ classes (e.g., digit recognition 0–9 on MNIST)

### Regression

Output space is **continuous**:

$$f: \mathbb{R}^d \to \mathbb{R}$$

Examples: predicting house prices, object coordinate detection.

### Structured Output

Output is a complex structure (vector, tensor, sequence) with meaningful relationships between elements:
- **Semantic segmentation**: output is a per-pixel label map (tensor)
- **Image captioning**: output is a sequence of words (CNN + LSTM / Transformer)
- **Machine translation**: sequence-to-sequence mapping ($f: \mathcal{X} \to \mathcal{Y}$)

Deep learning excels at structured output because it can model complex dependencies in both input and output spaces.

### Semi-Supervised Learning

A hybrid: dataset contains both labeled and **unlabeled** examples. The goal is to leverage the unlabeled portion to improve learning performance.

## 2. Unsupervised Learning

The model is trained using **unlabeled data** only. The goal is to discover hidden structure or patterns.

$$\mathcal{T} = \{\mathbf{x}_1, \ldots, \mathbf{x}_m\}$$

### Clustering

Group data points into clusters based on similarity, without prior knowledge of group definitions. Output: **hidden structure** in the data.

Examples: genomics (group individuals by genetic similarity), social network analysis (community detection).

### Density Estimation

Learn the underlying **probability distribution** $p(\mathbf{x})$ of the data. Useful for **anomaly detection**: flag points that fall in low-density regions (outliers).

### Dimensionality Reduction

Map high-dimensional data $\mathbf{x} \in \mathbb{R}^d$ into a lower-dimensional space $\mathbb{R}^k$ with $k \ll d$, preserving the most important features.

Tool: **Autoencoders (AEs)** — encoder maps to latent space, decoder reconstructs the input. Trained by minimizing reconstruction loss.

**t-SNE**: a visualization technique that maps high-dimensional representations to 2D/3D while preserving local structure. Commonly used to inspect what a neural network has learned.

### Unsupervised Deep Learning

Neural networks can be applied to unsupervised tasks:
- **Deep Clustering**: a network automatically learns useful representations, then clusters them — no hand-engineered features needed
- **DINO** (self-DIstillation with NO labels): self-supervised method using a teacher-student paradigm; achieves strong representations without any labels

## 3. Reinforcement Learning (RL)

An **agent** learns by interacting with an **environment**, performing actions and receiving feedback in the form of rewards or penalties.

$$\text{Goal: maximize cumulative reward over time}$$

### Key Components

| Component | Description |
|---|---|
| **States** | Possible configurations the agent can encounter |
| **Actions** | Choices the agent can make to change the state |
| **Rewards** | Feedback signal from the environment (positive or negative) |
| **Policy** | Strategy mapping states to actions |

The process is modeled as a **Markov Decision Process (MDP)**.

*Example — Chess:*
- States: valid board configurations
- Actions: legal moves
- Rewards: +reward for capturing pieces, −reward for losing pieces

### Deep Reinforcement Learning (DRL)

Traditional RL struggles when the state/action space is huge. **DRL** combines RL with deep neural networks to approximate:
- The **value function** (expected future reward per state)
- The **policy** (strategy the agent follows)

Notable applications:
- **AlphaGo**: first AI to defeat a world champion at Go, using self-play and DRL
- **DQN**: uses deep Q-networks to play Atari games directly from pixel input
- **Robotics**: training robots to pick up objects in simulation before real-world deployment

## Summary Table

| Paradigm | Data | Goal | Examples |
|---|---|---|---|
| **Supervised** | Labeled $(x, y)$ | Learn $f: x \to y$ | Classification, regression, segmentation |
| **Unsupervised** | Unlabeled $x$ | Discover structure | Clustering, density estimation, dim. reduction |
| **Reinforcement** | Rewards from env. | Maximize cumulative reward | Game playing, robotics |
