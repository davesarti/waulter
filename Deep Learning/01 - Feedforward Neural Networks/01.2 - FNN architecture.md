## Structure

A feedforward neural network can be thought of as a **composition of functions**, where each function represents a layer of the network:

$$f(\mathbf{x}) = f^{(i)}\!\left(f^{(i-1)}\!\left(\ldots f^{(2)}\!\left(f^{(1)}(\mathbf{x})\right)\ldots\right)\right)$$

- $f^{(1)}$ is the first layer (input layer)
- $f^{(i)}$ is the output of the $i$-th layer
- The **depth** of the network is defined by the total number of layers (i.e. the number of functions $f^{(i)}$ involved)

Information flows through a **directed acyclic graph (DAG)**: strictly from input to output, passing through intermediate computations in each layer.

![[img_ffn_arch.png]]

### Input Layer

Each node corresponds to one **input feature**. No computations or transformations are applied here.

### Hidden Layers

Neurons in the hidden layers perform **nonlinear computations** on the input data through the application of **weights** and [[01.5 - Activation Functions|activation functions]].

The main role of the hidden layers is to **capture and represent complex, abstract features** of the input data.

### Output Layer

The output layer produces the **desired prediction**. Its structure depends on the task:

| Task | Nodes | Activation |
|---|---|---|
| Binary classification | 1 | Sigmoid |
| Multiclass classification | One per class | Softmax |
| Regression | 1 (or more) | Linear / none |

## Overcoming the Limitations of Linear Models

Linear models (e.g. SVMs) rely on choosing a fixed feature mapping $\phi$ (**nonlinear mapping of input data in feature space**) to handle non-linear problems. This is limiting in practice. FFNs overcome the limitations of linear models by **learning complex, nonlinear functions directly from data**, capturing relationships that a hyperplane decision boundary cannot.

## Training a Neural Network

Training means **optimizing the parameters** $\mathbf{W}$ (weights) so that $f(X, \mathbf{W})$ approximates the target function $f(X)$ as closely as possible. This is done via [[02.1 - The Gradient Descent Algorithm|gradient descent]] — an iterative approach to minimizing a cost function.

The key design choices when building a neural network are:

| Element | Role |
|---|---|
| **Cost function** | Measures error between predicted and desired output |
| **Output representation** | How the prediction is encoded (probabilities, raw values, …) |
| **Activation functions** | Introduce nonlinearity in each layer |
| **Architecture** | Number of layers, neurons per layer |
| **Optimizer** | Algorithm used to update weights (SGD, Adam, …) |
| **Regularization** | Techniques to reduce overfitting and improve generalization |

> [!note] Key difference from linear models
> In linear models the loss is **convex** — convergence to the global optimum is guaranteed. In neural networks the loss is **nonconvex**, leading to greater complexity and no guarantee of reaching a global optimum.
