## Maximum Likelihood Estimation

Given a dataset $\mathcal{X} = \{x_1, x_2, \ldots, x_N\}$ of $N$ i.i.d. samples, we fit a parametric model $p(x \mid \theta)$ by choosing the parameters $\theta$ that make the observed data **as probable as possible** under the model.

### Likelihood Function

The **likelihood** is the joint probability of all observed data under the model:

$$L(\theta) = p(\mathcal{X} \mid \theta) = \prod_{i=1}^{N} p(x_i \mid \theta)$$

### Log-Likelihood

Products of many small probabilities cause **numerical underflow**. Taking the log converts the product into a sum — and since $\log$ is monotonically increasing, it preserves the location of the maximum:

$$\ell(\theta) = \log L(\theta) = \sum_{i=1}^{N} \log p(x_i \mid \theta)$$

The **MLE estimate** is then:

$$\hat{\theta}_{\text{MLE}} = \arg\max_{\theta}\; \ell(\theta)$$

To solve analytically: differentiate $\ell(\theta)$ with respect to $\theta$, set the gradient to zero, and solve for $\theta$.

### Conditional MLE — Supervised Setting

When each data point also carries a label $y_i$, we model the **conditional distribution** $p(y \mid x, \theta)$ instead. The likelihood becomes:

$$L(\theta) = p(\mathcal{Y} \mid \mathcal{X}, \theta) = \prod_{i=1}^{N} p(y_i \mid x_i, \theta)$$

$$\ell(\theta) = \sum_{i=1}^{N} \log p(y_i \mid x_i, \theta)$$

$$\hat{\theta}_{\text{MLE}} = \arg\max_{\theta}\; \sum_{i=1}^{N} \log p(y_i \mid x_i, \theta)$$

This is the foundation of supervised learning: **maximizing the conditional log-likelihood is equivalent to minimizing the negative log-likelihood**, which gives rise to the loss functions used in logistic regression and neural networks (e.g. cross-entropy).

## Logistic Regression

Logistic regression is a **binary classifier** that models the posterior probability $p(y=1 \mid x, \theta)$ directly. Unlike the original [[00.2 - Artificial Neuron|perceptron]] (same structure but step function as activation), it outputs a **smooth probability** via the [[Sigmoid|Sigmoid function]].

The model is:

$$p(y = 1 \mid x, \theta) = \sigma(\theta^T x) = \frac{1}{1 + e^{-\theta^T x}}$$

$$p(y = 0 \mid x, \theta) = 1 - \sigma(\theta^T x)$$

These two cases collapse into a single expression:

$$p(y \mid x, \theta) = \sigma(\theta^T x)^{y}\,(1 - \sigma(\theta^T x))^{1-y}, \qquad y \in \{0, 1\}$$

This is a **Bernoulli distribution** parameterized by $\sigma(\theta^T x)$.

### MLE for Logistic Regression

Applying conditional MLE, the log-likelihood over the training set is:

$$\ell(\theta) = \sum_{i=1}^{N} \left[ y_i \log \sigma(\theta^T x_i) + (1 - y_i) \log (1 - \sigma(\theta^T x_i)) \right]$$

**Maximizing** $\ell(\theta)$ is equivalent to **minimizing** the [[Binary Cross-Entropy Loss]].
Unlike the perceptron, this loss has **no closed-form solution** — the sigmoid introduces non-linearity. Parameters are found via [[02.1 - The Gradient Descent Algorithm|gradient descent]]:

$$\theta \leftarrow \theta - \eta\, \nabla_\theta \mathcal{L}(\theta)$$

### Limitations and connection to FNNs

Logistic regression is still a **linear model**: the decision boundary $\theta^T x = 0$ is a hyperplane. It cannot capture non-linear relationships in the data. **Feedforward Neural Networks** stack multiple layers of logistic-regression-like units to learn hierarchical, non-linear representations.
