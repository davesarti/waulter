## Unit Types

The choice of **output unit** is not independent of the choice of **loss function** — choosing one over another can be convenient for the cost function we want to use (e.g., sigmoid and binary cross-entropy).

## Linear Units

Linear Units play a key role in the intermediate and output layers of neural networks. They apply a **linear transformation to the inputs** by combining the weights associated with the inputs with the input values themselves.

### Formula

$$\hat{y} = W^T h + b$$

where $\hat{y}$ is the predicted output, $W$ are the weights, $h$ are the features from the previous layer, and $b$ is the bias term. The output is a **linear combination of the inputs** — no activation is applied.

## Softmax Units

Softmax Units are used in the **output layer** of neural networks for Multiclass Classification. They transform the unnormalized scores (logits) from the last linear layer into a **normalized probability distribution**, allowing the model to assign a probability to each class for a given input.
