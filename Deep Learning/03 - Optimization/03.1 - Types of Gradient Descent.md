## Overview

[[02.1 - The Gradient Descent Algorithm|Gradient descent]] algorithms differ in **how much data they use per update step** and **how they adapt the learning rate**. The progression below goes from the simplest approach to the most sophisticated.

### Empirical Loss

Every variant below is really just a different way of estimating the same quantity: the **empirical loss** (empirical risk) — the average of the per-example loss $L$ over a set of training examples:

$$\hat{L}(\mathbf{w}) = \frac{1}{N}\sum_{i=1}^{N} L(f(\mathbf{x}^{(i)}, \mathbf{w}), y^{(i)})$$

This is an *estimate* of the true (expected) risk over the data-generating distribution, which is unknown and can only be approximated using the finite training set. The gradient $\hat{\mathbf{g}}$ used in each update rule is simply $\nabla_\mathbf{w}\hat{L}(\mathbf{w})$, computed over however many examples the variant uses per step:

- **[[Batch Gradient Descent|BGD]]** — all $N$ examples → an exact, low-variance estimate of $\hat{L}$.
- **[[Stochastic Gradient Descent|SGD]]** — a single example → a cheap, high-variance estimate of $\hat{L}$.
- **[[Mini-Batch Gradient Descent|Mini-batch GD]]** — a small subset → a compromise between the two.
