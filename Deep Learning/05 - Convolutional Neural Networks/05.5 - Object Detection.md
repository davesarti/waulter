## What is Object Detection?

Object detection requires **simultaneously**:
1. **Classifying** objects present in the image
2. **Localising** them via **bounding boxes**

It is therefore a joint **classification + regression** task. The input is an image; the output is a set of *(class label, bounding box)* pairs for every object in the scene.

This is harder than image classification due to:
- **Data sparsity** — objects occupy only a fraction of the image
- **Difficulty in accurate localisation** — bounding box prediction is a continuous regression problem

## Evolution Summary

- **R-CNN**: CNN features replace hand-crafted ones
- **Fast R-CNN**: one shared forward pass for the whole image
- **Faster R-CNN**: region proposals are learned, not hand-crafted
- **YOLO**: collapses the entire pipeline into a single network pass
