## Overview

CNN architectures for image classification have evolved from the pioneering LeNet (1998) to modern ConvNeXt (2022), each addressing the limitations of its predecessor.

| VGGNet       | 2014 | Depth as key factor — stacked 3×3 convs       |
| ------------ | ---- | --------------------------------------------- |
| Architecture | Year | Key Innovation                                |
| LeNet        | 1998 | First CNN — conv + subsampling + FC           |
| AlexNet      | 2012 | Deep learning revolution — GPU, ReLU, Dropout |
| ZFNet        | 2013 | Smaller kernels + DeconvNet explainability    |
| GoogleNet    | 2014 | Inception modules — multi-scale, fewer params |
| ResNet       | 2015 | Skip connections — solves degradation problem |
| ConvNeXt     | 2022 | CNN competitive with Transformers             |
