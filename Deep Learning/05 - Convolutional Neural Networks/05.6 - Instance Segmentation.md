## What is Instance Segmentation?

Instance segmentation assigns a **label to each individual pixel** of an image, distinguishing separate instances of objects of the same class.

| Task | Output |
|---|---|
| **Classification** | Single class label for the whole image |
| **Object Detection** | Bounding boxes + class labels per object |
| **Instance Segmentation** | Per-pixel label + instance identity |
