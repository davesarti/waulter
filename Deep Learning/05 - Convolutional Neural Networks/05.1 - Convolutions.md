## Visual Cortex

Inspiration for CNNs comes from the **visual cortex** (Hubel & Wiesel, 1962). The brain recognises objects through a hierarchy of areas, each extracting progressively more complex features.

- **Early layers**: edges, corners, simple shapes
- **Middle layers**: complex shapes
- **AIT**: full object representations

Two key cell types mirror CNN mechanisms:
- **Simple cells** → receptive fields, local edge detectors (≈ conv filters)
- **Complex cells** → position-invariant responses (≈ pooling)

## Core Idea

CNNs **replace general matrix multiplication with convolution** in at least one of their layers. A convolution takes a matrix portion of the input (defined by a kernel) and produces a scalar via the dot product between pixel values and kernel weights. Sliding the kernel across the entire input produces a **feature map**.

$$S(i,j) = \sum_m \sum_n I(m,n)\, K(i-m,\, j-n)$$

Filters are **not set randomly** — they are **optimized during training** to best fit the architecture, loss function and data. Each filter learns to activate in response to a specific feature at a specific spatial location.

## Parameters

Two fundamental parameters control the size and shape of the output:

### Padding

Adds values (typically zeros) around the edges of the input **before** applying the convolution.

| Mode | Behaviour |
|---|---|
| **Valid** | No padding — output is smaller than input |
| **Same** (zero-padding) | Output is the same size as the input |

### Stride

Number of pixels the kernel moves at each step along the input.

- **Stride = 1** → most common, output same size as input (with padding)
- **Stride > 1** → larger displacement → **smaller output**

### Output Size Formula

$$\text{Output size} = \frac{N - K + 2P}{S} + 1$$

| Symbol | Meaning |
|---|---|
| $N$ | Input size |
| $K$ | Kernel size |
| $P$ | Padding |
| $S$ | Stride |

## Note on Dimensionality

When speaking of "2D convolutions" in CNNs, the operation actually runs on **3D tensors (volumes)** — the 2D example is a simplification. Architectures like AlexNet or VGGNet use fully 3D convolutional operations.
