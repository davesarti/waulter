## Overview

A CNN is a **specialised feedforward network** designed for structured data (images). Compared to a plain [[01.2 - FNN architecture|feedforward]] net applied to images, CNNs avoid losing spatial relationships between pixels and dramatically reduce the number of parameters via two core properties:

- **Local connectivity** — each neuron connects to only a small region of the previous layer (its **receptive field**), capturing local spatial features
- **Weight sharing** — the same filter is applied across the entire image, enabling translation-invariant feature detection with far fewer parameters

---

## Layer-by-Layer Structure

### 1. Input Image
Raw pixel values represented as a multidimensional array (height × width × channels).

### 2. Convolution Layer
Filters (kernels) slide over the input and produce **feature maps** — one per filter. Each feature map highlights the presence of a specific pattern (edge, texture, shape) learned during training.

### 3. Non-linearity
A [[ReLU]] activation is applied element-wise after convolution. This adds non-linearity to the model — allowing the network to learn complex relationships — **without altering the receptive fields**.

### 4. Spatial Pooling
Reduces the spatial size of feature maps, decreasing the number of parameters and controlling overfitting. Common variants:
- Max pooling, which keeps only the maximum value in each pooling window
- Average pooling, which computes the average value in each pooling window
Pooling creates a **spatially invariant representation**: relevant features are preserved even if slightly shifted in the image.

### 5. [[03.2 - Normalization|Normalization]] Layer *(optional)*
Normalises feature maps before passing them to the next layer. Ensures **data remains in an appropriate range** and facilitates the learning process.

### 6. Feature Maps
The output of the previous steps. Each feature map is a simplified representation of the image in terms of a specific pattern or structure. These are passed as input to subsequent layers for further processing.

---

## Fully Connected Head

After several convolutional + pooling blocks, the final feature maps are flattened and passed through one or more fully connected layers to produce the final output (e.g. class scores).
