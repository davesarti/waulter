Practical tricks for stabilizing [[09.1 - Generative Adversarial Networks (GANs)|GAN]] training.

## Feature Matching

Stabilizes training by changing the Generator's objective: instead of directly trying to fool the Discriminator, the Generator matches the **statistics of features from an intermediate Discriminator layer** between real and generated data. By minimizing the difference between these feature statistics, the Generator avoids overfitting to the Discriminator's current decision boundary, yielding more stable training and higher-quality samples.

## Mini-batch Discrimination

Helps the Generator produce **more diverse outputs** by letting the Discriminator examine relationships *between* samples in a mini-batch. An additional Discriminator layer computes pairwise differences between samples, so the Discriminator can tell if the Generator is producing similar/identical samples. This encourages the Generator to widen its output variety, directly counteracting **mode collapse**.

## Virtual Batch Normalization (VBN)

Extends regular [[Batch Normalization]], which makes a network's output for one example highly dependent on the other examples in the same minibatch (an unwanted coupling). In VBN, each example is normalized using statistics from a **fixed reference batch**, chosen once at the start of training, and itself.

The reference batch is normalized using only its own statistics, removing the minibatch-dependence problem.
