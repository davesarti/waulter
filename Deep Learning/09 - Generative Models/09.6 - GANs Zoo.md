## Image-to-Image Translation (Pix2Pix)

**Pix2Pix**, is a conditional GAN for image-to-image translation. The Generator transforms an input image into an output image; the Discriminator evaluates how realistic and consistent the generated image looks relative to the input. Applications include photo-to-sketch translation, colorization, and resolution enhancement. Training requires **paired** data.

## Text-to-Image Synthesis

GANs can be used to synthesize images from text. The Generator receives a textual description plus a noise vector and produces an image matching that description; the Discriminator distinguishes real (image, matching description) pairs from generated ones. Applications include generating scenes from verbal descriptions or artwork from text prompts.
