## Core Idea

Gaussian noise can be used as a **regularizer** in neural networks by injecting it into inputs, weights, or labels during training.

---

## Noise on Inputs

Each input component $x_i$ is perturbed:

$$x_i = x_i + \mathcal{N}(0, \sigma_i^2)$$

The resulting output $y_j$ of a layer becomes:

$$y_j = y_j + \mathcal{N}(0, w_i^2 \sigma_i^2)$$

This contributes additively to the quadratic error, causing the model to **minimize square weights as well** → equivalent to [[04.2 - Parameter Norm Penalties|L2 regularization]] through noisy inputs.

---

## Noise on Weights

Adding noise to weights makes the learned function **smoother** and encourages the network to be **more robust to random variations** in training data — a kind of "flexibility" in model weights. Especially useful in weight-space regions where individual weight variations don't significantly affect output.

---

## Noise on Labels (Label Smoothing)

Adding noise to labels **discourages overconfident model behavior**. In cross-entropy loss, the model can assign very large values to the correct class and very small values to wrong classes. Label smoothing — randomly modifying labels — prevents this overestimation of class probabilities.

---

## Key Effect

> **High levels of noise generate a smoother function.** This is useful in applications where a smooth function is preferred.
