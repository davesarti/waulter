## Core Idea

Multi-Task Learning (MTL) trains the model to perform **more than one task simultaneously**.
By sharing representations across tasks, the model is forced to learn more general features, acting as a regularizer.

---

## Architecture

In MTL, several tasks **share the same input data and some intermediate layers**, but may have **separate final layers** for each task.

Parameters come in two types:

| Type | Description | Location in network |
|---|---|---|
| **Task-specific** | Designed for a specific task; learn from task-specific data | Upper layers |
| **Generic (shared)** | Shared across all tasks; benefit from combined data | Lower layers |

---

## Parameters Tying

MTL allows applying **soft constraints on model parameters** — enforcing some parameters to be similar to others (**"Parameters Tying"**). Useful when multiple models perform the same type of classification on slightly different data, enforcing consistency across models.
