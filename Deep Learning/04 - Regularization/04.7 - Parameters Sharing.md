## Core Idea

Parameter Sharing enforces that **certain parameters within the network are exactly the same**. This reduces model complexity and enables sharing of relevant information across different parts of the network.

**Advantage over [[04.6 - Multi-Task Learning|Parameters Tying**]]: only a subset of parameters need to be stored in memory.

---

## In [[05.2 - Inside a CNN|Convolutional Neural Networks]] (CNNs)

Parameter sharing is a **key feature** of CNNs, enabled by two main properties:
### 1. Local Connectivity
Neurons in one layer are **connected to only a small region of the previous layer**. This allows CNNs to capture local image features efficiently.

### 2. Weight Sharing between Spatial Positions
CNNs learn **displacement-invariant filter kernels** — the same filter is applied across all spatial positions. This:
- Reduces the number of parameters needed
- Makes the model **able to recognize the same features in different parts of the image**

> Example: a picture of a cat is still recognized as a cat even if it is shifted by some pixels.
