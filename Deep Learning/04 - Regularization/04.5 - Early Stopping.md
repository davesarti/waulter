## Core Idea

Early Stopping prevents the model from becoming **too specialized on training data** by monitoring performance on a **validation set** during training and stopping when validation performance starts to deteriorate — even if training loss continues to improve.

---

## Procedure

1. Start with small initial weights
2. At each step, if the **validation error improves** → save a copy of the model parameters
3. When training ends → return the parameters **for which validation error was smallest**

The number of training steps is treated as a **hyperparameter to optimize**.

---

## Key Trade-off

The stopping point must be **selected carefully**:
- **Stopping too early** → model hasn't learned important information → underfitting
- **Stopping too late** → model overfits to training data

The number of epochs before stopping must be carefully calibrated during training.

---

## Why It Works

Early stopping implicitly constrains model complexity by limiting the number of gradient updates. It is equivalent to a form of regularization on the effective capacity of the model over training time.
