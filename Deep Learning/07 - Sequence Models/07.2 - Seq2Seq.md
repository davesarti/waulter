The distinguishing factor of Seq2Seq is **end-to-end learning**: the model handles the entire translation process from inputting the original text to outputting the translated text, without separate components or intermediate steps.

To achieve this, the model introduces the **encoder-decoder** approach to handle input sequences of variable length.

---

## Encoder

An [[06.3 - Long Short-Term Memory (LSTM)|LSTM]] responsible for mapping the variable-length input phrase into a **fixed-dimensional vector** called the **context vector**. This vector serves as the connection between the encoder and the decoder.

## Decoder

An **LSTM** that maps the fixed context vector into a **variable-length output sequence**, generating the translation word by word.

---

## Limitation

> [!warning] Context Vector Bottleneck
> The "C" block must capture the entire input sequence. The latent representation **cannot contain all the information** about the input — this becomes particularly problematic with **long sequences**, where the decoder quality degrades as input length grows. This limitation motivates the need for an attention model.
