## Motivation

How do we learn the weights of a neural network? Several approaches were explored before backpropagation:

| Approach | Idea | Problem |
|---|---|---|
| **Perturb one weight at a time** | Change each weight, check if loss improves, keep the change | Extremely slow — requires many full passes over training data |
| **Perturb all weights simultaneously** | Change all weights at once and correlate with performance | Equally inefficient and very hard to implement |
| **Perturb only activations** | Fewer activations than weights — smaller search space | Still inefficient |

*Therefore, how can we achieve more efficient learning?* This is where **backpropagation** comes in.

---

## Backpropagation

Backpropagation is a learning algorithm consisting of **three main steps**:

1. **Forward Propagation** — summation of inputs, production of activations, and propagation of output through the network.
2. **Error Estimation** — comparison of the network's predictions with the ground-truth labels via the loss function.
3. **Backpropagation** — propagation of the error signal backward through the network, computing gradients and using them to update the weights.

### Key Idea

By computing the **derivatives of the error with respect to the hidden unit activations**, we can understand exactly how each hidden unit affects the overall error of the network. This gives us:

- A clear view of the **separate contribution** of each hidden unit to the error.
- The information needed to determine the **optimal direction to update each weight**.

Once the gradients are known, weights are updated via [[02.1 - The Gradient Descent Algorithm|gradient descent]] to progressively minimize the overall error and move closer to the optimal solution.
