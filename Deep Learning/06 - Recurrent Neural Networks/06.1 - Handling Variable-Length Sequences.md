## Motivation

In this section we focus on models that can handle **variable-length structures**, more specifically sequences, such as text (a sequence of strings).

**Recurrent Neural Networks (RNNs)** are flexible tools that can perform many different tasks, classified by their input/output structure:

| Type                                | Description                    | Example                 |
| ----------------------------------- | ------------------------------ | ----------------------- |
| **One-to-many**                     | Single input → sequence output | Image captioning        |
| **Many-to-one**                     | Sequence input → single output | Sentiment analysis      |
| **Many-to-many** (same length)      | Sequence → aligned sequence    | Parts of speech tagging |
| **Many-to-many** (different length) | Sequence → sequence            | Machine translation     |

---

## 6.1.1 Multiple2Single: Sentiment Analysis

In sentiment analysis, the model must classify a product, restaurant, or other item as **positive, neutral, or negative** based on reviews. The network receives inputs of varying sizes. Each word is transformed into a **hidden representation that reflects the context and propagates through subsequent words**, as words are not independent of each other.

This propagation occurs **unidirectionally**, similar to a feedforward neural network. The key difference from an FNN is that instead of mapping a single fixed-size input to a fixed-size output, the model takes multiple inputs and produces a **single label**. Predictions are typically made about the **last hidden state**, which should encode the context of all previous words.

---

## 6.1.2 Single2Multiple: Image Captioning

In image captioning, the network receives a **fixed input** (an image) but must produce a **variable-length output** (a sentence describing the image). The latent representation of the image from a CNN is **combined with the latent representations of words**, modelling the dependencies between them. This maps a single input to multiple outputs, generating several words that describe the image.

---

## 6.1.3 Multiple2Multiple: Machine Translation

In machine translation, the task is to translate a sentence from one language to another — both the input and output are sequences of variable length. Each word in the input sentence is mapped to a hidden representation that takes into account the context of the preceding words. The network then uses these representations to generate the translated sentence word by word, **maintaining sequential dependencies between words**, producing an accurate translation that reflects the meaning of the original.
