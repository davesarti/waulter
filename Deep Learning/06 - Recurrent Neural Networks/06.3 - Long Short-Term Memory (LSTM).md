## Motivation

The [[06.2 - Vanilla RNN|classical RNN]] suffers from an inefficient cell design: efforts to improve learning have not produced significant improvements on the vanishing gradient problem due to inherent limitations of the cell structure. To solve this, **LSTM** was introduced in **"Long Short-term Memory" (Sepp Hochreiter)**.

The LSTM cell not only produces the hidden state $h_t$, but adds another component called the **Memory Cell** $c_t$, which is responsible for maintaining and deleting information based on the input context. This means that **some of the previous information must be remembered, some must be forgotten, and some new information must be added to memory**.

## Gates

![[Pasted image 20260705185223.png]]

Within an LSTM cell there are three parametric components called **Gates**.

> [!info] Input Gate
> Can allow the input signal ($x_t$ and $h_{t-1}$) to alter the state of the memory cell or block it.
> Its output $i_t$ is computed by the sigmoid function applied to $x_t$ and $h_{t-1}$, with its own parameters $W_i$:
> $$i_t = \sigma\!\left(W_i \begin{pmatrix} x_t \\ h_{t-1} \end{pmatrix} + b_i\right)$$
> $i_t$ acts as a trade-off between the information from the current input ($x_t$, $h_{t-1}$) and the information encoded by the previous cell ($c_{t-1}$).

> [!danger] Forget Gate
> Can modulate the self-recurrent connection of the memory cell, allowing the cell to remember or forget its previous state as needed.
> Its output $f_t$ is computed by the sigmoid function applied to $x_t$ and $h_{t-1}$, with its own parameters $W_f$:
> $$f_t = \sigma\!\left(W_f \begin{pmatrix} x_t \\ h_{t-1} \end{pmatrix} + b_f\right)$$

> [!success] Output Gate
> Can allow the state of the memory cell ($c_t$) to have an effect on other neurons, thus affecting the output of the LSTM unit ($h_t$).
> A sigmoid layer decides which parts of the cell state the model will output, with its own parameters $W_o$:
> $$o_t = \sigma\!\left(W_o \begin{pmatrix} x_t \\ h_{t-1} \end{pmatrix} + b_o\right)$$

All three gates (plus the input modulation $g_t$) share the same computational structure — they differ only in weights and activation — and can be written compactly as:

$$\begin{pmatrix} i_t \\ f_t \\ o_t \\ g_t \end{pmatrix} = \begin{pmatrix} \sigma \\ \sigma \\ \sigma \\ \tanh \end{pmatrix} W \begin{pmatrix} x_t \\ h_{t-1} \end{pmatrix}$$

---

## Memory Cell Update

The memory cell is updated as a combination of the forget and input gates:

$$c_t = f_t \odot c_{t-1} + i_t \odot g_t$$

| Term | Meaning |
|---|---|
| $f_t \odot c_{t-1}$ | Forget gate decides how much of the **previous state** to retain |
| $i_t \odot g_t$ | Input gate decides how much of the **new information** $g_t$ to add |

In short: **the forget gate modulates how much of the previous state to retain**, while **the input gate modulates how much of the new information is to be added to the cell state**.

---

## Output Calculation

A tanh layer is applied to the memory cell to squash values between −1 and 1, then multiplied element-wise by the output gate:

$$h_t = o_t \odot \tanh(c_t)$$

---

## Why LSTM Mitigates Vanishing Gradients

Although there are many nonlinearity functions in an LSTM cell, the calculations to update $c_t$ are **linear** — the gradient flow from $c_t$ to $c_{t-1}$ involves only **backpropagation through addition and element-wise multiplication**, not matrix multiplication or nonlinear functions. This uninterrupted gradient highway through the cell state is what allows LSTMs to learn long-range dependencies that vanilla RNNs cannot.
