## Core Idea

Recurrent neural networks are, in essence, **neural networks with cycles**.

The Vanilla RNN performs the same parametric function for each input $x_t$ (each marked with a timestep), while the output $h_t$ (the hidden representation at the corresponding timestep) depends on the previous computation $h_{t-1}$.

After producing the output, $h_t$ is **used to generate the hidden representation of the next RNN cell** ($h_{t+1}$). To make a decision $y_t$, a linear layer can be applied at the end of a cell, considering both the current input and the output learned from the previous input.

There are two representations for an RNN:
- **Folded** — synthetic, compact view
- **Unfolded** — explicit description of the computations across time steps

## Cell Equations

The hidden state at time $t$ is computed as:

$$h_t = f_W(x_t, h_{t-1}) = \tanh W \begin{pmatrix} x_t \\ h_{t-1} \end{pmatrix} = \tanh(W_x x_t + W_h h_{t-1})$$

| Symbol | Meaning |
|---|---|
| $x_t$ | Input at time $t$ |
| $h_t$ | Hidden state at time $t$ |
| $h_{t-1}$ | Previous hidden state |
| $W_x$ | Weights for the current input |
| $W_h$ | Weights for the previous hidden state |

The prediction at each step is:

$$y_t = \text{softmax}(W_y h_t + b_y)$$

---

## Key Properties

**Weight sharing across timesteps**: $W_x$, $W_h$, and $W_y$ are shared between all timestep iterations, allowing the model to capture **sequential dependencies within the data**.

**Gradient vanishing is more severe** due to the tanh activation and long time horizons.

---

## BPTT Without Truncation

The total error is the sum of per-timestep errors:

$$e = e_1 + e_2 + e_3 + \ldots$$

To update the weights associated with the hidden state we compute $\frac{\partial e}{\partial W_h}$.

**Sum over time:**

$$\frac{\partial e}{\partial W_h} = \sum_{t=1}^{T} \frac{\partial e_t}{\partial W_h}$$

**Each term** decomposes via the chain rule:

$$\frac{\partial e_t}{\partial W_h} = \frac{\partial e_t}{\partial h_t} \cdot \frac{\partial h_t}{\partial W_h}$$

### Time Dependencies

Hidden states depend on each other backwards through time: $h_3 \to h_2 \to h_1$. Error therefore **flows backward through time**, with the chain rule applied repeatedly.

**General form** — for any early timestep:

$$\frac{\partial e}{\partial h_1} = \frac{\partial e}{\partial h_T} \cdot \prod_{t=2}^{T} \frac{\partial h_t}{\partial h_{t-1}}$$

**For the weights associated with hidden states:**

$$\frac{\partial e}{\partial W_h} \propto \sum_{t} \left( \frac{\partial e}{\partial h_t} \cdot \prod_{k=1}^{t} \frac{\partial h_k}{\partial h_{k-1}} \right)$$

The product of many Jacobians causes the **gradient to shrink exponentially** → **vanishing gradient is more severe in RNNs than in feedforward networks**, because thousands of timesteps means thousands of chained derivatives that can make the gradient vanish or explode.

---

### Gradient for $W_y$

$W_y$ connects $h_t$ directly to $y_t = \text{softmax}(W_y h_t + b_y)$ at each timestep, with **no recurrence**. The gradient is simply a sum of independent per-timestep contributions:

$$\frac{\partial e}{\partial W_y} = \sum_{t} \frac{\partial e_t}{\partial y_t} \cdot \frac{\partial y_t}{\partial W_y}$$

There is **no product of Jacobians through time** — the gradient flows directly from the loss to $W_y$ at each step. $W_y$ does **not** suffer from vanishing gradients.

---

### Gradient for $W_x$

$W_x$ maps the current input $x_t$ into the hidden state at every timestep. Because $h_t$ feeds into $h_{t+1}$, changing $W_x$ at step $j$ ripples forward through all subsequent hidden states. The gradient must therefore chain back through time exactly like $W_h$:

$$\frac{\partial e}{\partial W_x} \propto \sum_{t} \left( \frac{\partial e}{\partial h_t} \cdot \prod_{k=1}^{t} \frac{\partial h_k}{\partial h_{k-1}} \right)$$

The **same product of Jacobians** appears. The only structural difference from $W_h$ is the leaf term at the end of the chain: for $W_h$ it involves $h_{j-1}$, for $W_x$ it involves $x_j$. The vanishing gradient problem is equally severe.

---

### Summary

| Weight | Path to error | Temporal chaining | Vanishing gradient |
|--------|--------------|-------------------|--------------------|
| $W_y$ | $e_t \leftarrow y_t \leftarrow W_y$ | ✗ | ✗ |
| $W_x$ | $e_t \leftarrow h_t \leftarrow \ldots \leftarrow h_j \leftarrow W_x$ | ✓ | ✓ |
| $W_h$ | $e_t \leftarrow h_t \leftarrow \ldots \leftarrow h_j \leftarrow W_h$ | ✓ | ✓ |

## Truncated BPTT (Backpropagation Through Time)

To address the cost and vanishing gradient issues, **Truncated BPTT** is used.

Instead of running the entire sequence through the network, the sequence is divided into **smaller blocks of fixed length**. Each block is treated as a separate training unit, so the network only works with small chunks at a time.

After presenting a block, **[[02.3 - Backpropagation Step by Step|backpropagation]] is performed only for a limited number of backward time steps** rather than traversing the full sequence. This reduces the computational cost and limits how far back the gradient must flow.

### Parameters

| Parameter | Role |
|---|---|
| $k_1$ | Length of each block (how many timesteps are presented) |
| $k_2$ | Number of time steps over which to backpropagate within each block |

### Algorithm

1. Present a sequence of $k_1$ timesteps of input/output pairs to the network.
2. Unroll the network, then calculate and accumulate errors across $k_2$ timesteps.
3. Roll up the network and update weights.
4. Repeat the process.

Adjusting $k_1$ and $k_2$ balances **training speed** against the network's ability to **capture long-range dependencies**.

## Variations

### Multi-layer RNN

Multiple RNN layers stacked on top of each other, where **each layer receives the hidden states of the layer below as its input**. Deeper layers learn progressively more abstract representations of the sequence. Typical depth: **2–4 layers**.

### Bi-directional RNN

Processes the input sequence in **both the forward and the reverse direction** simultaneously, giving each timestep access to both past and future context. Popular in **speech recognition** and other tasks where the full sequence is available at once.

> [!warning] Limitation
> A bi-directional RNN **cannot be used autoregressively** — since it requires the full sequence to run the reverse pass, future tokens are not available at inference time. It therefore **cannot generate text** or any other sequential output token by token.
