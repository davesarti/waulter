The **Vision Transformer (ViT)**, extends the self-attention mechanism used in [[08.2 - Transformer|Transformers]] to images, moving the model from the world of NLP tokens to visual data.

Self-attention, applied to images, becomes **learning the relationships between pixels in fixed areas of the image**. To make this tractable, the input image is divided into a predetermined number of **patches** before being passed to the encoder.

![[Pasted image 20260707172353.png]]

The input patches are linearly projected into a smaller embedding size to reduce complexity, and combined with a **positional embedding**. 

In addition, ViT introduces a special learnable **class token**, a randomly initialized embedding vector learned during training (not obtained through embedding but learned and shared between each inference of the network!!).  Its role is to collect global information from the whole image through the Transformer's self-attention mechanism: at the end of the process, the **MLP head only looks at the class token of the last layer**, ignoring every other output.

> [!info] Data Efficiency
> Transformers lack the **inductive biases** built into CNNs, such as translation equivariance and locality, and therefore **do not generalize well when trained on insufficient amounts of data**. This gap closes (and can reverse) when the model is pre-trained on much larger datasets (14M–300M images).

## From ViT to DeiT: Making Transformers Data-Efficient

The data-hungriness described above is precisely the problem that **DeiT (Data-efficient image Transformers)** was designed to solve:

 DeiT was introduced to train ViT-like models on **ImageNet alone**, using modest compute (e.g., a single GPU, in under three days).
 To achieve this, DeiT incorporates a **distillation** strategy that improves data efficiency and generalization.

**Distillation** is a **model compression technique** where:

- A **small student model** is trained to mimic the behavior of a **larger teacher model**.
- The student learns not only from ground-truth labels, but also from the **soft predictions of the teacher**.

### Soft vs. Hard Distillation

**Soft distillation** minimizes the KL divergence between the teacher's and the student's softmax outputs, encouraging distributional similarity. A **temperature factor** ($\tau$) is used to soften the probabilities before computing the divergence:

$$\mathcal{L}_{\text{global}} = (1-\lambda)\,\mathcal{L}_{\text{CE}}(\psi(Z_s), y) + \lambda \tau^2\, \text{KL}\big(\psi(Z_s/\tau), \psi(Z_t/\tau)\big)$$

**Hard distillation**, instead, uses the teacher's predicted label ($y_t$) as an additional supervision signal: the student is trained using both the true label and the teacher's (hard) prediction. Surprisingly, hard distillation works very well in practice, despite being conceptually simpler than the soft variant:

$$\mathcal{L}_{\text{global}}^{\text{hardDistill}} = \frac{1}{2}\,\mathcal{L}_{\text{CE}}(\psi(Z_s), y) + \frac{1}{2}\,\mathcal{L}_{\text{CE}}(\psi(Z_s), y_t)$$

### Distillation Token

DeiT introduces a special **distillation token**, added to the input sequence alongside the class and patch tokens.

Both tokens flow through the same stack of self-attention + FFN blocks as the patch tokens.

At the output, the distillation token is **supervised to match the teacher's prediction** ($\mathcal{L}_{\text{teacher}}$), while the class token is still supervised with the ground truth via cross-entropy ($\mathcal{L}_{\text{CE}}$). For this reason two linear classifiers are needed.
