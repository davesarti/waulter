This chapter traces the shift from [[06.2 - Vanilla RNN|RNN]]s to [[08.2 - Transformer|Transformers]], starting with early [[05.2 - Inside a CNN|CNN]]-based approaches to sequence modeling: rather than processing sequences step-by-step like RNNs, CNNs extract features hierarchically from local regions, treating sequences as patch-like inputs; this yields uniform, parameter-shared processing and strong GPU parallelism, offering efficient local-pattern capture as an alternative to RNNs and setting the stage for Transformer architectures.

## Dilation

**Dilation**, which refers to the spacing between the elements (or receptive fields) of a filter as it moves across the input sequence.

![[img_dilated_convolution_rates.png]]

**Dilated convolutions** introduce gaps between the elements of the filter, allowing the network to capture information over larger spans of the input sequence. This approach extends the **receptive field** of the convolutional filter, enabling it to incorporate more context from the input data while maintaining the computational efficiency of the original kernel size.
