The **Swin Transformer** model builds **hierarchical feature maps** by using dynamic partitioning, improving the accuracy of localized representations.

## Why Swin? ViT's Limitations

One key issue with ViT is that each encoder block processes the full image globally, and always in the same uniform context. This becomes inefficient and limits its applicability to more complex tasks.

## Hierarchical Feature Maps

![[Pasted image 20260707170855.png|309]]

While ViT keeps a fixed patch resolution (and therefore a single-scale feature map) throughout the network, Swin progressively merges neighbouring patches at each stage, producing feature maps at decreasing resolution ($4\times$, $8\times$, $16\times$, ...).

## Window-Based Self-Attention

At each level, Swin partitions the image into regular **windows** and calculates self-attention within each window using **window-based multi-head self-attention (W-MSA)**.

When moving to the next level, the window layout is updated via a **shifted window multi-head self-attention (SW-MSA)**: the window partitioning is shifted creating new windows that may partially or completely overlap the previous windows.

This approach allows the model to manage and integrate information from different parts of the image effectively, capturing long-range dependencies without global attention, while remaining computationally efficient.

## Architecture

![[Pasted image 20260707171428.png]]

The image ($H \times W \times 3$) is split into non-overlapping patches by **Patch Partition** and linearly embedded. The backbone is then organized into **4 stages**:

- Each stage is composed of a number of **Swin Transformer Blocks** operating at a fixed resolution.
- Between stages, a **Patch Merging** layer concatenates each group of $2\times2$ neighboring patches and applies a linear layer, halving the resolution ($H/4 \to H/8 \to H/16 \to H/32$) while doubling the channel dimension ($C \to 2C \to 4C \to 8C$). This is what produces the hierarchical, multi-scale feature maps.
